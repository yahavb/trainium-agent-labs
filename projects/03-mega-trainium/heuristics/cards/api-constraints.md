# API constraints (NKI 0.6.0)

- When using .indirect() views on nc_matmul operands (trn3), keep tile_position at (0,0), use a Tensor-Engine float dtype, and do not use indirection on moving when is_transpose=True. FIX: Drop tiling mode and cast to bf16/fp16/fp8 when gathering operands; index starts on a 32-partition quadrant boundary.
- Apply .indirect() to an MX data tile and its scale tile together with the same index (or to neither). FIX: Use the identical index view on both members of the pair; keep tile_position (0,0).
- Give quantize_mx a bf16/fp16 SBUF src with partition size a multiple of 32 (<=128) and free size a multiple of 4; dst free size is src free / 4. FIX: Cast to bf16 first; pad free dim to a multiple of 4; allocate dst (P, F//4) x4 dtype and dst_scale e8m0fnu in SBUF.
- Pass engine=nisa.engine.sync or nisa.engine.scalar to dma_copy only together with dge_mode=nisa.dge_mode.hwdge. FIX: Add dge_mode=nisa.dge_mode.hwdge or drop engine.
- Use the DMA priority (0-3, lower is higher priority) argument only on trn3. FIX: Gate priority usage on nisa.get_nc_version()==gen4.
- Do not pass dst_rmw_op/unique_indices to dma_copy; use nisa.dma_compute(dst, [src, dst], reduce_op=nl.add) for read-modify-write. FIX: First iteration dma_copy; later iterations dma_compute(dst=acc, srcs=[src.ap(...), acc], reduce_op=nl.add, unique_indices=True).
- .ap(pattern=[[stride,count],...]) overrides shape/strides entirely; list the partition dim first for on-chip tensors and keep counts consistent with the instruction's expected element count. FIX: Start from t.get_pattern() and edit strides; pass offset explicitly when shifting.
- Treat nl.load/nl.store as experimental conveniences; for control and portability write nisa.dma_copy(dst=..., src=...) with explicit SBUF tiles. FIX: sb = nl.ndarray(shape, dtype, buffer=nl.sbuf); nisa.dma_copy(dst=sb, src=hbm[...]).
- Give activation a float32 scale (scalar or [N,1] vector) and a bias that is an [N,1] vector on trn1 (scalar allowed from trn2) of any dtype except tfloat32. FIX: Allocate bias as nl.ndarray((N,1), ...) in SBUF; keep scale fp32.
- Make activation/activate2 data and dst share the same partition size (<=128) and the same number of elements per partition. FIX: Reshape views rather than changing element counts.
- Use only the Scalar Engine activation set as activation op: copy, square, sigmoid, relu, prelu, gelu, gelu_dx, gelu_apprx_tanh, gelu_apprx_sigmoid, gelu_apprx_sigmoid_dx, silu, silu_dx, tanh, softplus, mish, erf, erf_dx, exp, log, sin, arctan, sqrt, rsqrt, reciprocal, sign, abs. FIX: Compose from supported ops (cos via sin(x+pi/2) with range reduction; power via exp(y*log(x)) on valid ranges) or use tensor_tensor(op=nl.power) on GpSimd.
- When a Scalar Engine instruction writes through a .indirect() scatter view, the dst must be in SBUF, not PSUM. FIX: Scatter into an SBUF tile, or run the op on Vector Engine.
- Use nisa.activate2 only on trn3 and only with (op0,op1) in {(multiply,add),(multiply,subtract),(multiply,bypass),(add,bypass),(subtract,bypass),(bypass,bypass)}. FIX: Reorder as (multiply, add) with reverse flags, or fall back to tensor_scalar + activation.
- Prefer nisa.activation(reduce_op=nl.add, reduce_cmd=nisa.reduce_cmd.reset_reduce, reduce_res=...) over nisa.activation_reduce. FIX: Replace with nisa.activation(..., reduce_op=nl.add, reduce_cmd=nisa.reduce_cmd.reset_reduce, reduce_res=out).
- Use reduce_op=nl.add for nisa.activation's fused reduction; the richer set (add, maximum, minimum, abs_max, abs_min) is only available through activate2 on trn3. FIX: Compute row max with tensor_reduce(op=nl.maximum) or range_select/select_reduce on Vector Engine.
- Do not pass a bias to nisa.activation(op=nl.reciprocal) on trn1. FIX: Add epsilon with tensor_scalar first, or use nisa.reciprocal on Vector Engine.
- In tensor_scalar_reduce use one arithmetic op0, reduce_op in {add, multiply, max, min}, pass reduce_init only with load_reduce, and do not rely on reverse0 (unsupported). FIX: Chain a tensor_scalar first if two ops are needed; use reduce_cmd=load_reduce with reduce_init for warm starts.
- Make tensor_scalar operand0/operand1 either compile-time constants or (data.shape[0],1) fp32 tiles; for unary op0 (abs, rsqrt) pass operand0=None or 0. FIX: Cast the per-partition vector to fp32 (tensor_copy) and shape it (P,1).
- Reduce only over the trailing contiguous free axes with tensor_reduce/nl.sum/nl.max etc. (e.g. (3,), (2,3), (1,2,3) for a 4-D tile); axis 0 is never reducible. FIX: Rearrange the tile so the reduced dims are last, or transpose for partition reductions.
- Size the tensor_reduce dst so elements per partition equal the product of the non-reduced free dims (1 when all free dims are reduced); use keepdims=True to keep broadcastable shape. FIX: dst = nl.ndarray((P,1), ...) or keepdims=True.

FIX: dst in SBUF; pattern product == prod(dst.shape[1:]); cast on write via dst dtype.
