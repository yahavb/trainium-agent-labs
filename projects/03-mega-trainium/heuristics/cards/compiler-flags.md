# Compiler flags and options

- Expect nki.simulate to model bf16/fp8 precisely by default (NKI_PRECISE_FP=1) and to reproduce hardware sin extrapolation; set NKI_PRECISE_FP=0 only to restore fp32 approximation. FIX: Run NKI_SIMULATOR=1 or nki.simulate(kernel)(...) with default precision; compare with rtol per dtype.
- Leave address rotation enabled (default) so multi-buffered tensors rotate addresses; disable with Kernel.disable_address_rotation() only when manual addresses must be stable. FIX: kernel = nki.jit(fn).disable_address_rotation().
- Compile LNC2 kernels with Kernel.enable_core_barrier_checker() during development to fail compilation on cross-PNC races. FIX: kernel = nki.jit(fn).enable_core_barrier_checker(); disable for production builds.
- Guard version-specific code with nki.compiler.get_compiler_version() (0.6.0 -> major 0, minor 6). FIX: v = nki.compiler.get_compiler_version(); if v.minor >= 6: use fori_loop.
- Run CPU simulation via nki.simulate(kernel)(numpy args) or NKI_SIMULATOR=1, select target with NEURON_PLATFORM_TARGET_OVERRIDE, and use nl.device_print(prefix, tensor) with NEURON_RT_DEBUG_OUTPUT_DIR for on-device dumps. FIX: export NEURON_PLATFORM_TARGET_OVERRIDE=trn2; nki.simulate(kernel[lnc])(...).
- Use nki.compiler.parallel_compile(kernel_specs, compile_opts_dict={'target': ...}, artifacts_base_dir, max_workers) with unique config_ids for sweeping kernel hyperparameters. FIX: Build KernelSpec(kernel_module, kernel_func_name, inputs, outputs, hyperparams, config_id).
- Compile with --lnc (or --logical-nc-config) equal to the runtime NEURON_LOGICAL_NC_CONFIG; only 1 or 2 are valid and 2 is the trn2 default. FIX: torch_neuronx.trace(..., compiler_args='--lnc=1') with os.environ['NEURON_LOGICAL_NC_CONFIG']='1'.
- Set NEURON_FRAMEWORK_DEBUG=1 (save NEFF), XLA_IR_DEBUG=1 and XLA_HLO_DEBUG=1 before compiling to get profiler source mapping, then capture with neuron-explorer capture --profile-nth-exec=2. FIX: neuron-explorer capture -n ./compiler_workdir/graph.neff -s profile.ntff --profile-nth-exec=2; neuron-explorer view --data-path ./ws (ports 3001/3002).
- Set NEURON_PLATFORM_TARGET_OVERRIDE=trn2 (or trn3) when compiling kernels on a host without the target device so generation-specific features (hwdge, double FP8, transpose mode) are selected. FIX: os.environ['NEURON_PLATFORM_TARGET_OVERRIDE'] = 'trn2'
- Control graph-level precision with --auto-cast / --auto-cast-type (FP32 -> BF16 by default) and integer behavior with --native-int64 (trn2+) and --implicit-integer-downcast. FIX: Pass explicit compiler_args in torch_neuronx.trace.
- Expect the NKI compiler to keep your instruction order, allocation and engine choices; it only does light middle/back-end passes and is inserted late into the graph compile. FIX: Optimize explicitly in the kernel (engine selection, tile sizes, buffering).
- Expect recompiles to hit the on-disk Neuron Persistent Cache at /var/tmp/neuron-compile-cache; clear it when changing kernels that produce identical graph hashes. FIX: Remove the cache entry or change the graph.
- If NKI_DMA_TRANSPOSE_AS_PE_TRANSPOSE=true, restrict manual PSUM allocation to banks 0-6: the compiler lowers dma_transpose to an identity matmul that uses bank 7 as scratch. FIX: num_banks = 7 if os.environ.get('NKI_DMA_TRANSPOSE_AS_PE_TRANSPOSE','').lower()=='true' else 8
- When hand-scheduling with manual SBUF/PSUM addresses (old API), decorate with @nki.compiler.skip_middle_end_transformations and pass --internal-skip-backend-allocation-opt-nki --disable-internal-io-dge; otherwise the compiler re-allocates and breaks the pipeline. FIX: @nki.compiler.skip_middle_end_transformations @nki.baremetal(artifacts_dir='debug', additional_compile_opt='--internal-skip-backend-allocation-opt-nki --disable-internal-io-dge')
- Debug and profile with --lnc 1 (single NeuronCore) and only switch to the default --lnc 2 (trn2/trn3) when explicitly targeting multi-core execution. FIX: os.environ['NEURON_CC_FLAGS'] = '--target trn2 --lnc 1'.
- Set NEURON_CC_FLAGS --target and NEURON_PLATFORM_TARGET_OVERRIDE to the same platform (trn1/trn1n/inf2/trn2/trn3) and do not pass platform_target= or mode= to @nki.jit. FIX: os.environ['NEURON_CC_FLAGS']='--target trn2 --lnc 1'; os.environ['NEURON_PLATFORM_TARGET_OVERRIDE']='trn2'; plain @nki.jit.
- Pin each concurrent process to its own NeuronCore with NEURON_RT_VISIBLE_CORES and give it a unique NEURON_RT_INSPECT_OUTPUT_DIR. FIX: os.environ['NEURON_RT_VISIBLE_CORES']='0'; os.environ['NEURON_RT_INSPECT_OUTPUT_DIR']=f'./output/session-{os.getpid()}'.
- Add --verbose=info (or debug) only when inspecting compiler behaviour; read log-neuron-cc.txt in /tmp/$USER/neuroncc_compile_workdir/<uuid>/ for allocation and optimization decisions. FIX: NEURON_CC_FLAGS='--target trn2 --lnc 1 --verbose=info'; ls -lt /tmp/$USER/neuroncc_compile_workdir/ | head -5.
- Run PyTorch scripts under NKI_SIMULATOR=1 to execute every @nki.jit kernel on the CPU simulator with no code changes; for JAX call nki.simulate(kernel)(...) explicitly. FIX: NKI_SIMULATOR=1 python my_script.py   or   nki.simulate(my_kernel)(a_np, b_np)
- Set NEURON_PLATFORM_TARGET_OVERRIDE to trn1/gen2, trn2/gen3 or trn3/gen4 explicitly; when unset the simulator auto-detects and otherwise defaults to trn3. FIX: os.environ['NEURON_PLATFORM_TARGET_OVERRIDE']='trn2'
- Write kernels knowing that every for/if/while and Python expression is evaluated at specialization time; only nki.isa.* calls and dynamic_range loops become device operations. FIX: Use nl.dynamic_range(n) / register bounds for big or runtime loops; use nl.device_print for device output.
- Disable the compiler's heuristic middle-end loop reordering/fusion (skip_middle_end_transformations) for hand-tuned kernels whose loop structure is deliberate. FIX: Set the skip_middle_end_transformations directive on the kernel.
