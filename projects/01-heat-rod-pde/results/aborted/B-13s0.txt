
=========== level1.3 ===========
Solve the heat equation on a rod.

  u_t = 2 * u_xx,   for 0 < x < 2, t > 0
  u(0, t) = 0 and u(2, t) = 0
  u(x, 0) = -x**2 + 2*x

The starting shape is not a single sine wave, so the answer is a sum of the allowed waves, each with its own coefficient and its own decay rate. Keep enough terms that the starting shape matches to within 0.5 percent.
Each coefficient is an integral: c_n = (2/2) * Integral(u(x, 0) * sin(n*pi*x/2), (x, 0, 2)). Work it out for n = 1, 2, 3, ... instead of guessing, and simplify each one to a number.

On the last line write exactly
  u(x, t) = <expression>
Write every term out with its numbers filled in, in Python syntax, like this:
  u(x, t) = 3*exp(-2*pi**2*t)*sin(pi*x) - 0.5*exp(-8*pi**2*t)*sin(2*pi*x)
Use exp, sin, cos, pi and ** for powers. No summation sign, no unknown constants, no LaTeX.
